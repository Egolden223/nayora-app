Comment uploader sur GitHub
---------------------------
1. Ouvre https://github.com/Egolden223/nayora-app
2. Pour chaque fichier, va dans le dossier correspondant (ex. src/lib/)
3. Clique "Add file" → "Upload files" (ou édite le fichier existant)
4. Dépose le fichier du même chemin (remplace l’existant)
5. Message de commit : "fix: restore dating_final + UI improvements (logo, filters, SW v4)"
6. Commit sur la branche main

Ordre recommandé (priorité) :
  1. src/lib/dating_final.ts   ← critique (fichier actuellement cassé)
  2. src/lib/dating.ts
  3. src/components/wordmark.tsx
  4. public/sw.js
  5. le reste

Après le push, Vercel redéploiera automatiquement (ou redéploie manuellement).
